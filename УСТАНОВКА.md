# 📱 Как поставить «Вихрь топоров» на айфон

Айфон умеет ставить сайты как приложения: иконка на экране «Домой», полный экран, работа без интернета.
Для этого игра должна лежать в интернете по ссылке. Проще всего бесплатно выложить её на **GitHub Pages**.

## Шаг 1. Выложить игру (один раз, ~10 минут, на компьютере)
1. Зарегистрируйся на **github.com** (бесплатно).
2. Справа сверху нажми **«+» → New repository**.
   - Repository name: `vihr-toporov`
   - Выбери **Public**. Бесплатный GitHub Pages работает только с публичными репозиториями, поэтому код игры будет виден всем.
   - Нажми **Create repository**.
3. На странице репозитория нажми ссылку **«uploading an existing file»**.
4. Перетащи туда **6 файлов** из папки `C:\Игра`:
   - `index.html`
   - `manifest.json`
   - `sw.js`
   - `icon-192.png`
   - `icon-512.png`
   - `apple-touch-icon.png`

   (`CONCEPT.md`, `serve.ps1` и этот файл можно не загружать.)
5. Внизу нажми **Commit changes**.
6. Открой **Settings → Pages**. В разделе *Branch* выбери **main** и папку **/ (root)**, нажми **Save**.
7. Подожди 1–2 минуты и обнови страницу. Сверху появится ссылка вида
   `https://ТВОЙ-НИК.github.io/vihr-toporov/`

## Шаг 2. Установить на айфон
1. Открой эту ссылку **именно в Safari** (в Chrome на айфоне так не получится).
2. Нажми кнопку **«Поделиться»** (квадрат со стрелкой вверх).
3. Пролистай вниз и выбери **«На экран Домой»** → **«Добавить»**.
4. На экране появится иконка с топорами. Запускай игру с неё: так она открывается на весь экран и работает без интернета.

## Как обновлять игру
Когда я сделаю новый этап:
1. В репозитории на GitHub нажми **Add file → Upload files** и загрузи новые файлы поверх старых (обычно `index.html` и `sw.js`).
2. Нажми **Commit changes** и подожди минуту.
3. На айфоне открой игру **с интернетом**. Если обновление не подтянулось, закрой игру и открой ещё раз.

Прогресс при обновлении **не теряется**.

## ⚠️ Про сохранения
- Игра, установленная на экран «Домой», хранит прогресс **отдельно от Safari**. То, что ты наиграл в Safari, в приложении не появится.
- Если удалить иконку, прогресс удалится вместе с ней.
- Поэтому время от времени заходи в **⚙️ → «📤 Экспорт сохранения»**, копируй код и сохраняй в Заметках. Вернуть прогресс: **⚙️ → «📥 Загрузить сохранение»**.

## Поиграть на компьютере
- **Быстро:** двойной щелчок по `index.html`. Без офлайн-режима, но играть можно.
- **Как на сайте:** правый клик по `serve.ps1` → «Выполнить с помощью PowerShell», потом открой в браузере `http://localhost:8080`.
